# Desktop client

Запустите из корня проекта командой `python -m client.main`. Приложение открывает одно окно с боковой панелью мест и постоянно видимой картой.

Места и города читаются из `data/offline.db`. Используйте поиск и категории в боковой панели, добавляйте места в маршрут и нажмите «Найти меня на карте», чтобы запросить геопозицию. На macOS разрешите доступ в «Системные настройки → Конфиденциальность и безопасность → Службы геолокации».

Для загрузки тайлов OpenStreetMap требуется интернет.
